Touch Note

Política de privacidad

Última actualización: 22 de mayo de 2026.

Touch Note es una plataforma para planificar contenido, administrar empresas o clientes, crear guiones, organizar recursos, conectar cuentas sociales autorizadas y operar servicios digitales como campañas, hosting, dominios, cobros y páginas web. Esta política explica qué datos tratamos, para qué los usamos y cómo puedes solicitar acceso, corrección o eliminación.

Responsable del tratamiento

La operación de esta instalación corresponde a Touch Studio / Touch Company. Para solicitudes relacionadas con privacidad, eliminación de datos, soporte o acceso a información puedes escribir a ia@touch.com.co.

Datos que podemos recopilar

Podemos guardar datos de cuenta como nombre, correo, proveedor de acceso, rol, plan, empresa activa, permisos, fecha de creación y estado de la sesión. También podemos guardar información operativa creada por el usuario: empresas, clientes, servicios, facturas o cuentas de cobro, calendario editorial, publicaciones, copies, guiones, prompts, notas, enlaces de recursos, portadas, estados de aprobación y trabajos por red.

Cuando conectas servicios externos podemos guardar identificadores, estados de conexión, tokens de acceso, tokens de actualización, permisos concedidos, fecha de conexión y metadatos mínimos necesarios para mostrar las cuentas conectadas y ejecutar acciones autorizadas. Los tokens se guardan en backend o base de datos segura y no deben exponerse en el navegador.

Facebook Login, Meta, Instagram y Facebook Pages

Si decides iniciar sesión con Facebook o conectar una cuenta Meta, Touch Note puede solicitar permisos oficiales de Meta para identificarte, leer datos básicos autorizados, listar páginas, asociar cuentas de Instagram profesionales y preparar publicaciones o campañas según los permisos aprobados por Meta. La app solo usa estos datos para prestar las funciones que el usuario solicita dentro de Touch Note.

No vendemos datos de Facebook, Instagram ni Meta. No compartimos datos de estas plataformas con terceros para publicidad externa. Las publicaciones, campañas o acciones hacia Meta solo se ejecutan cuando el usuario conecta la cuenta correspondiente y autoriza la operación en la plataforma.

Google Drive, TikTok, LinkedIn, YouTube y otros proveedores

Si conectas Google Drive u otro proveedor, usamos los permisos concedidos para mostrar o seleccionar archivos, guardar referencias de recursos, preparar piezas de contenido o publicar cuando el usuario lo confirme. Cada integración puede tener permisos, revisión y condiciones propias. Puedes desconectar cuentas desde la app o desde el panel del proveedor correspondiente.

Pagos, hosting, dominios y servicios de agencia

Cuando compres o administres servicios desde Touch Note, podemos guardar información relacionada con la orden: servicio comprado, cliente vinculado, valor, moneda, estado, fechas, dominio, contacto técnico y datos necesarios para aprovisionar hosting, dominios, campañas, páginas web o soporte. Las credenciales técnicas de proveedores como cPanel/WHM, eNom, Stripe o Supabase se manejan desde backend mediante variables de entorno.

Uso de inteligencia artificial

Touch Note puede usar proveedores de IA como OpenAI o Gemini para sugerir guiones, copies, campañas, prompts o ideas de contenido. La información enviada a IA se limita al contexto necesario para generar la respuesta solicitada por el usuario. Evita ingresar datos sensibles que no quieras procesar con proveedores externos.

Finalidades del tratamiento

Usamos los datos para autenticar usuarios, mantener sesiones, administrar permisos por empresa, crear y organizar publicaciones, generar guiones, gestionar clientes, operar cobros, conectar APIs autorizadas, enviar correos transaccionales, registrar eventos del sistema, prevenir abuso, diagnosticar errores y mejorar la experiencia del producto.

Conservación y eliminación

Conservamos los datos mientras la cuenta, empresa, servicio o integración esté activa, o durante el tiempo necesario para cumplir obligaciones operativas, legales o de seguridad. Algunas cuentas o empresas eliminadas pueden pasar a una papelera recuperable temporal antes de ser borradas definitivamente.

Puedes solicitar eliminación de tus datos escribiendo a ia@touch.com.co o visitando /legal/data-deletion.html. También puedes revocar permisos desde Facebook, Instagram, Google, TikTok u otros proveedores conectados.

Seguridad

Usamos medidas técnicas razonables para proteger datos, incluyendo sesiones HttpOnly, separación de secretos en backend, variables de entorno, tokens OAuth fuera del frontend y almacenamiento controlado. Aun así, ningún sistema conectado a internet puede garantizar seguridad absoluta.

Compartición de datos

Podemos compartir datos únicamente con proveedores necesarios para operar la plataforma, por ejemplo hosting, base de datos, correo transaccional, pagos, APIs sociales, almacenamiento o servicios de IA. Estos proveedores procesan información según sus propias condiciones y solo para prestar las funciones solicitadas.

Derechos del usuario

Puedes solicitar acceso, corrección, actualización, portabilidad o eliminación de tus datos. También puedes pedir que desconectemos una integración o eliminemos tokens asociados a una cuenta social. Para ejercer estos derechos, escribe a ia@touch.com.co indicando el correo de tu cuenta y la solicitud concreta.

Menores de edad

Touch Note está orientado a empresas, agencias, marcas personales y profesionales. No está dirigido a menores de edad ni busca recopilar intencionalmente datos de menores.

Cambios a esta política

Podemos actualizar esta política para reflejar nuevas funciones, integraciones o requisitos legales. La versión vigente estará disponible públicamente en esta misma URL: https://app.touch.com.co/legal/privacy.html.
