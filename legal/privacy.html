Politica de privacidad

Flowpost Studio ayuda a equipos y empresas a organizar, programar y publicar contenido en redes sociales.

Datos que podemos guardar

Empresas, cuentas conectadas, publicaciones, copys, estados, enlaces de medios y configuraciones de calendario.

Datos de TikTok y otras redes

Cuando un usuario conecte una cuenta, la app solicitara permisos mediante OAuth. Los tokens se guardaran solo en backend o base de datos segura. No se expondran tokens en el navegador.

Uso de datos

Los datos se usan para mostrar cuentas conectadas, preparar publicaciones, consultar informacion necesaria de creador y enviar contenido solo cuando el usuario lo autorice.

Eliminacion

El usuario podra solicitar desconectar una cuenta y eliminar datos asociados a esa conexion.

Contacto

Para soporte o solicitudes de datos, usa el correo de contacto configurado por el propietario de esta instalacion.
